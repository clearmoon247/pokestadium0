## What changed

- Added C for resident and fragment helpers, including state updates, buffer
  accessors, move-animation wrappers, geometry helpers, and by-value vector
  distance calculation. Candidates were checked with the actual file's types
  and declarations, with corrections to pointer scaling and argument types.
- Promoted existing battle-animation and math matches by retaining individual
  constants at their established addresses where neighboring assembly still
  interrupts the file's literal pool. Repeated equal-valued literals sometimes
  occupy distinct addresses and are kept distinct.
- Restored complete SDK modules using the vendored, unmodified ultralib 2.0I
  sources and verified IDO 5.3 settings. This includes synthesizer code,
  controller reads, matrix helpers, DMA and device access, task loading, EEPROM
  probing, video initialization, floating-point formatting, and memory sizing.
  Whole-module comparison also recovered private helper owners and removed
  misleading standalone stub/source groupings. SDK owner totals include some
  previously accepted C now owned by their complete SDK module.
- Split fragment 7 at `0x82005D90` so the preceding C function's trailing
  alignment word remains present and subsequent functions retain their PCs.
- Corrected imported data against Zero: five Japanese item descriptions
  (including the 130/170 power values), the preview scene layout, three model
  scale constants (`0.65f`), and a ribbon-sheet constant occupying pool padding.

## Runtime BSS and stored relocation data

Some fragment scratch addresses lie inside the stored image's relocation data.
Allocating a `NOLOAD` section there overlaps the preserved stored bytes. The
builder now uses a non-allocating `INFO` section for these in-image BSS addresses,
so C relocations resolve correctly while the original storage remains present.
BSS outside the stored image remains `NOLOAD`.

Section-size assertions, normal linker overlap checks, per-image comparisons,
and the complete ROM comparison remain enabled. A synthetic regression test
links a BSS reference over nonzero stored bytes and verifies both the resolved
address and the unchanged binary. No retail code bytes or raw instruction-word
fallback were added to C owners.
